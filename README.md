# msmoney

동탄역 기반 공인중개사 **미세스머니**(꼭티비채널)의 웹페이지 저장소입니다.
동탄·경기남부권의 아파트, 상가(식당·카페), 단독건물 매물 안내를 위한 소개 페이지와 부가 콘텐츠를 담고 있습니다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 메인 소개 페이지. 아파트 / 상가·창업 / 단독건물·투자 안내, 조건별 매물 찾기, 상담 연락처 |
| `tetris.html` | 쉬는 시간용 테트리스 게임 (PC 키보드·모바일 터치 지원) |
| `requirements.txt` | Python 의존성 목록 (현재는 없음, 안내 주석만 있음) |

빌드 과정 없이 HTML 파일 하나가 곧 페이지입니다. 글꼴은 Google Fonts와 jsDelivr(Pretendard)에서 불러옵니다.

## 로컬에서 보기

파일을 브라우저로 바로 열어도 되고, 아래처럼 간단한 서버를 띄워도 됩니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 수정 방법

- 문구·매물 정보는 `index.html` 본문에서 직접 고칩니다.
- 색상·글꼴은 `index.html` 상단 `<style>`의 `:root` 토큰(`--pine`, `--brass` 등)에서 한 번에 바꿀 수 있습니다.
